# Профиль Facade AI · спецификация 1.1

**Действующая версия для разработки.** [Спецификация 1.1](v1.1/specification.md) закрепляет профиль 4 vCPU, 16 ГиБ RAM, 200 ГиБ SSD/NVMe и объединяет функциональные требования, интерфейс, сервер, профиль VPS и критерии приёмки. Ниже сохранена трассировка исследований до 0.19.

**Пользователь и результат.** Инженер проектировщика НВФ получает точные адресуемые данные и устанавливает комплектность выбранной области. Для подтверждённой нехватки или противоречия он может сформировать письмо. У других исходов сохраняется заключение без внешнего документа.

**Границы поручения.** Независимое ревью архитектуры и переработка функциональной и технической спецификаций. Новый продукт получает отдельные БД, хранилище, API, правила, адаптеры, профили и установку. Исторический аудит — исследовательский материал.

**Профиль приложения.** Предложены TypeScript/Node.js для домена и backend, Svelte, PostgreSQL и многоходовые исследовательские Mastra Workflows с фиксацией каждого обращения. Обоснование и условие утверждения исключения из Rust-first приведены в [решении](design-review.md). SDK и модели не получают права на изменение каталога, подтверждение за инженера или внешнюю отправку письма.

**Проверяемый результат.** Через браузер принять пакет, проверить независимые чтения разными моделями, их расхождения и исходы по оригиналам. Зафиксировать заключение при полном, проблемном, неопределённом и смешанном составе. Подтвердить только адресные запросы, сверить экспорт или отсутствие документа, затем принять досылку. [Сквозная приёмка](qualification.md)

**Состояние.** Базовый Git-коммит репозитория — ebed916. Редакция 0.19 добавляет [проверку двух значений и адресное продолжение](reader-continuation.md). Редакция 0.18 отдельно проверяет [доказательство непередачи](delivery-proof.md). Редакция 0.17 добавляет исполняемый профиль двух автономных читателей и ведущего при споре. [Контракт и границы слепого теста](conditional-review.md). Правила расхода общего лимита и возобновления действуют для обычной загрузки. [Охват пакета](reading-coverage.md) · [Вопросы, доказательства и досылка](engineering-questions.md). Продуктовые команды сборки и доставки определяются при реализации.

[Проверка схем](../contracts/check_examples.py) · [Программа сквозной квалификации](qualification.md)

**Контроль оригинала.** Синтетический PDF сопоставлен с SHA-256 эталона. Poppler 26.02.0 определил две страницы 480 × 270 пунктов. На первой есть текстовый слой, на второй — только изображение. Оба листа отрисованы и осмотрены. Координаты четырёх значений при нативном чтении и OCR попали внутрь четырёх ожидаемых ячеек. Пересчёт по размеченным единицам дал 2, 3, 1200 и 900 мм. Вторая страница показала существенную ошибку при правильных числах: Tesseract 5.5.3 с языками rus+eng при ширине 720 пикселей прочитал напечатанное `R1` как `В1`. Это наблюдение для одной версии утилиты и одного изображения. Показатель качества продукта получают на штатном машинном результате после открытия исходников через приложение. [Синтетический оригинал](../fixtures/recognition/facade-materials.pdf) · [Независимый эталон](../fixtures/recognition/gold.json)

Команды для локальной сверки из корня репозитория:

```sh
pdfinfo fixtures/recognition/facade-materials.pdf
shasum -a 256 fixtures/recognition/facade-materials.pdf
pdftotext -bbox fixtures/recognition/facade-materials.pdf -
render_dir=$(mktemp -d)
render_dir=$(cd "$render_dir" && pwd -P)
pdftoppm -png -scale-to 720 fixtures/recognition/facade-materials.pdf "$render_dir/page"
tesseract "$render_dir/page-2.png" stdout -l rus+eng --psm 6 tsv
```

Локальная сверка ссылок охватила 13 документов, 59 локальных переходов и 33 источника прежнего проекта по закреплённым коммитам. Локальный результат 21.11.2026 — спецификация и проверенная фикстура. Живой прогон продукта, проверка планировщика под нагрузкой и решение инженера по полному письму остаются открытыми.
