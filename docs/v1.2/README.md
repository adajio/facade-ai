# Сводная редакция Facade AI 1.2

[Канонический текст в Markdown](Facade-AI-Specification-1.2.md) содержит основной раздел и приложения А, Б и В. [Word](Facade-AI-Specification-1.2.docx) собирается из этого файла. Номера D1–D13, AC01–AC08, R01–R07 и Б11/Б14 сохранены. Б12 описывает предметную матрицу, Б13 — помощника. В §8 закреплены приёмка А, Б0, Б1 и обязательная естественная приёмка.

Основание редакции — документы 1.1 на базе `e35fdde989147ec8b87dabda9722b895eb826d2e` и утверждённый 24.11.2026 план 1.2 с SHA-256 `0a0a7b69e9e96b3ec7f9b6a3b1d6ca05bb4db8161c6603bd3f9b37f36327e8c5`. Для контроля Б0 применяется редакция 1.1 с приоритетом нормативного дополнения в затронутой области. [Базовый текст](../v1.1/specification.md) · [Дополнение](../v1.1/intake-addendum.md)

## Сборка и сверка

В поставке 1.1 использовались сводный Markdown и Word, созданный через `python-docx`. В 1.2 та же пара файлов выпускается из одного текста. Для повторения использованы Python с `python-docx` 1.2.0 и Node.js с `marked` 17.0.5. Скрипт читает Markdown, проверяет локальные ссылки и якоря и создаёт DOCX. В свойствах Word сохраняется SHA-256 Markdown.

Из корня репозитория, с доступными `node`, модулем `marked` и `python-docx` для выбранного Python:

```sh
python3 docs/v1.2/export_word.py
python3 docs/v1.2/export_word.py --check
```

Для установленного отдельно окружения можно задать `FACADE_DOC_NODE` и `FACADE_DOC_MARKED` абсолютными путями к Node.js и пакету. `--check` повторяет сборку в памяти и сверяет её с сохранённым DOCX. Для внутренних переходов Word использует закладки. Ссылки на соседние документы рассчитаны на размещение обоих форматов в дереве репозитория.
