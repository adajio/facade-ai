## Сравнение и денежный допуск

Для прежнего первичного обхода, помощника только по запросу и сочетания с памятью используются одинаковые оригиналы и измерения. Машинный снимок сохраняется до позднего вопроса и действий инженера. Живое сравнение требует тех же маршрутов, байтов и допустимых операций при раздельных контекстах. Можно использовать офлайн-повтор сохранённых ответов. Он даёт техническое сравнение, включая точное место, смысл, единицу, фасад, исполнение и редакцию. Живые различия без отдельного измерения остаются открытыми.

Единый предел — **$5 на весь эксперимент**. В него входят первичные, повторные и последующие вызовы. Неизвестная попытка учитывается по резерву и сохраняет ключ эффекта. Допуск ограничен синтетическим проектом и утверждёнными хэшами. Перед отправкой шлюз сравнивает резерв конкретного запроса с подтверждённым расходом и открытыми резервами.

По прямому указанию владельца проверен ключ прежнего пилота. Служебный GET вернул HTTP 200. Вызовов генерации не было. Kimi `wafer/us` присутствует в ZDR-каталоге. Qwen `qwen4-max → alibaba` допускается на этом замороженном корпусе по политике `synthetic-research`. OpenRouter указывает для Alibaba хранение промптов без обучения. Для обоих маршрутов закрепляется точный провайдер без fallback. [OpenRouter API ключа](https://openrouter.ai/docs/api/api-reference/api-keys/get-current-api-key) · [Каталог ZDR](https://openrouter.ai/docs/api/api-reference/endpoints/list-endpoints-zdr) · [Политики провайдеров](https://openrouter.ai/providers)
