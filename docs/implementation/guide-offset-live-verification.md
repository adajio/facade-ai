## Вход и назначение

Все шесть файлов приняты штатной загрузкой с закрытой описью. Скачанные через API оригиналы совпали с SHA-256 нового манифеста и манифеста предыдущего прямого пилота. Новый проект `e82f9682-4fd0-4c8f-897f-79550fc0a7cb`, поколение `843498c5-295c-4906-917a-c772981d2e9c`. В опыте две ветви независимо читают два исходных адреса. Для каждого назначения отдельны сеанс, выдача reader и публикация наблюдений. ## Допуск и бюджет

Владелец через координатора согласовал до $5 на весь прогон, включая условную сверку. Новые назначения используют `gpt-6.1-terra` напрямую в CheaperInference с ZDR и `qwen/qwen3.8-max-0902` через OpenRouter с единственным маршрутом `alibaba`. В обоих назначениях `tool_choice: auto`. Допуск привязан к проекту, одной ревизии маршрутов, синтетическому классу и шести SHA-256. У Alibaba применён допуск хранения для этого синтетического комплекта. Рабочий ключ OpenRouter из последнего пилота прошёл проверку, более ранний ключ вернул 401. [Свидетельства допуска](</Volumes/ADATA SE920/OrbStack/.facade-ai-guide-offset-live-20261123/evidence/provider-preflight.json>) · [Конфигурация маршрутов](</Volumes/ADATA SE920/OrbStack/.facade-ai-guide-offset-live-20261123/evidence/route-plan.json>)

На 2 048 выходных токенов верхний резерв Terra $2,640361, Qwen $2,532348. Один оператор последовательно пропускает ходы. Первый расход Qwen $0,03719 подтверждён по ID генерации и по обновившемуся агрегату ключа. Задержка агрегата вызвала удержание. Продолжение использует сохранённый ответ. ## Уточнение физических границ и профиля Qwen

Проверены последние ответы и квитанции обоих заданий r3. После принятой цитаты 44 мм две последние команды PDF повторили `invalid_arguments`.
