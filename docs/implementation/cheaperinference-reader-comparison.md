# Независимый тест читателей CheaperInference

23 ноября 2026 года обе модели выполнены через прямой API CheaperInference. В штатном harness использованы шесть синтетических оригиналов и два файла досылки с заранее замороженным эталоном. Суммарный допуск составил $5. Адресные снимки, закрытый эталон, журнал запросов и настройки доступа хранятся вне репозитория.

| Фаза | Коммит | SHA-256 манифеста образа Linux arm64 |
|---|---|---|
| Первичная | `6137f99` | `048e32fa80958d449eb540b82ebe39ada3e5da73a63629c56daa08eefb2e3fd5` |
| Досылка | `ac0fecf` | `3b9b5fd21c039d9581079e468a91db0944524662df5ed26119da1c78687387b2` |

Для обеих пар согласованы одинаковые сборки по фазам, порядок выдачи корпуса, 32 хода на назначение, 2 048 токенов на ход, обязательный вызов инструмента, тайм-аут 180 секунд и допуск до 12 PNG. Sol назначен в ветвь A и на роль ведущего. Terra назначена в ветвь B. Код проверял выдачу по точному ID модели и принимал только расчётную квитанцию с подтверждённой ценой. [Контракт CheaperInference](https://www.cheaperinference.com/api-reference)

## Независимая оценка

Оценщик сопоставил штатные снимки с закрытым эталоном. Доставка означает, что адрес источника появился во входе модели. Сохранение означает, что harness принял наблюдение или его компонент с этим адресом. Показатели после досылки накопительные.

| Ветвь | Доставлено / сохранено из 14 первичных адресов | Доставлено / сохранено из 16 адресов после досылки |
|---|---:|---:|
| CheaperInference, `gpt-6.2-sol` | 14 / 14 | 16 / 16 |
| CheaperInference, `gpt-6.1-terra` | 14 / 14 | 16 / 16 |
| OpenRouter, Kimi Wafer US | 4 / 3 | 13 / 10 |
| OpenRouter, Qwen Alibaba | 4 / 0 | 4 / 0 |

В обеих фазах и в обеих парах возникло **0 задач сверки**. Для CheaperInference положительное чтение контрольных адресов сопровождалось нулём подтверждённых типов фасада и нулём допустимых пунктов письма. Обе ветви сохранили цитаты об отсутствии детали и о её получении после досылки. Цитата о получении дошла до инженера без привязки к фасаду. Стадия осталась неподтверждённой. В инженерных снимках v1 и v12 видны четыре фасадных контекста. Офлайн-перестроение одних и тех же 275 первичных наблюдений дало четыре контекста на `6137f99` и два на `ac0fecf`. В обоих офлайн-расчётах автоматические связи были построены заново.

Итог сверён с 318 расчётными квитанциями провайдера. Активных отправок, неизвестных исходов и повторных эффектов 0. При смене сборки сохранены все 291 первичный оплаченный эффект. Один оплаченный ответ Sol остался без доступных байтов. Другой ответ восстановлен по сохранённому завершению и квитанции без нового вызова. Дальнейшее чтение досылки остановил резерв на полный контекст. При остатке $2,638773 следующий запрос требовал $2,645481 для Sol или $2,640361 для Terra. Восемь основных назначений досылки и семь дочитываний остались удержанными.

## Переносимый адаптер

Адаптер использует штатный интерфейс `managed` gateway. Ему передаются проект, закреплённая ревизия, разрешённые SHA-256 оригиналов, квалифицированные точные маршруты, каталог закрытой трассы и ключ в памяти процесса. Проект и журнал должны быть выделенными. Внешняя отправка по умолчанию выключена. Перед оплатой gateway проверяет принадлежность опор, полномочия, сохранённое намерение и резерв. При восстановлении адаптер возвращает сохранённое завершение только для совпавших проекта, ревизии, маршрута, эффекта и отпечатка запроса.

Локальная проверка использует подстановку HTTP и временный каталог. Она проверяет сохранение входа и инструментов, отклонение чужих данных, учёт неподтверждённого результата, блокировку повтора и восстановление совпавшего ответа.

```sh
node --test test/acceptance/cheaperinference/cheaper-transport.test.mjs
```
