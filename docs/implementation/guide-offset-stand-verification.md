## Исходный результат

На образе `ac0fecf6a856f7de4bfacd7a6d74d390d619f3f6` штатный worker обработал очередь локальной фасадной привязки. API под ролью инженера вернул оба наблюдения и открыл сохранённые представления PDF и XLSX с ответом `200` и точным SHA-256. В актуальной и сохранённой первой оценке карточек пары ноль. Chromium подтвердил отсутствие карточки. В БД нет адресных дочитываний сравнения, заданий ведущего и писем. Во всех контекстах допустимых пунктов ноль, попытка создать письмо вернула `422 no_eligible_items`.

На непосредственном предшественнике `2fe29a5c139e812d5e2c88b3572984da6c2f5076` после обработки локальной фасадной привязки доступна карточка именно PDF 44 / XLSX `I3` 51. Её причины удержания включают непривязанный фасад, исполнение и редакцию. Штатный worker не создал адресного дочитывания. Отдельная карточка показывает те же числа для соседней ячейки `I4`. Значения совпадают, поэтому проверки различают ячейки по физическому адресу. В исторической оценке № 1 по-прежнему ноль карточек.

## Планировщик и допуск

На `717182275830190d36280b56d443c292c9f44909` расчёт кандидатов нашёл строку PDF `1.0.4.0` для обеих ветвей. У обоих корневых заданий действующие карты, текущие поколения, статус `done`, структурный блок нужной строки и ноль незакрытых попыток по их цепочке. На обычной офлайн-копии задачи не созданы. Исторический исследовательский транспорт `managed` несовместим со штатным runtime. При переносе строки маршрутов и разрешений убраны из рабочего каталога копии и сохранены в архивной схеме. Там обе ревизии совпадают с закреплёнными, а старые разрешения положительные. Этот результат описывает допуск в восстановленной копии; права на момент живого исследования проверяются по его протоколу. Карточка `I3` остаётся открытой с обеими опорами. На этой версии UI ещё не показывает причину отсутствия назначения.

На `d30bdef` в обычной офлайн-копии по-прежнему ноль заданий на адресное дочитывание. Для каждой ветви API возвращает `route_required`, а интерфейс объясняет, что для адресного дочитывания требуется доступ к закреплённому маршруту.
