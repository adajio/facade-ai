# Чтение исходных строк ведомостей

Обе модели получают одинаковый каталог и могут открыть любой лист или раздел по обычному адресу исходного reader. Ведомости ищутся по заголовкам исходника, шапкам, признакам выравнивания, текстовым отметкам о продолжении и структуре Word. Для DWG каталог также показывает пространства и сквозной текстовый индекс, для растровых материалов — адрес изображения. Сигналы каталога помогают выбрать участок для проверки. Модель устанавливает состав, связи строк и значения по источнику.

## Подключение к испытанию

Вспомогательный [адаптер](../experiments/package_review/schedule_reader.py) принимает словари документов и разделов существующего индекса. Один экземпляр можно использовать для независимых сеансов. В действующем локальном reader словари возвращает `reader._index()`.

| Вызов | Результат |
| --- | --- |
| `catalog(start=0, doc_ref=None)` | Все документы в выбранной области, число разделов и кандидатов по каждому, кандидаты в порядке описи. `doc_ref` ограничивает список одним документом. |
| `read(ref, start=0)` | Исходные строки всего листа или непрерывной части. Принимаются адреса страниц PDF, разделов Word, изображений, пространств, видов и текстовых индексов DWG. |
| `read(ref, start=0, columns=[left, right])` | Непрерывная выборка символов каждой строки PDF с исходными адресами строк. `column_scope` показывает полный, выданный и непокрытый символьные диапазоны. |
| `reader.view(view_ref, rect=None)` | Изображение по адресу из каталога или чтения. Для вырезки `rect` содержит нормированные координаты `[x0, y0, x1, y1]` от верхнего левого угла. |

Каталог и чтение возвращают данные, пригодные для сериализации в JSON. Строки `rows` сохраняют пробелы и порядок индекса. Адрес `d1:p2#L7` соответствует той же восьмой строке, которую старый reader показывает с номером `0007`. Такой адрес действителен в пределах того же неизменного индекса. В строке DWG поле `source_ref`, если доступно, указывает на исходный объект. `text_layers` различает текстовый слой PDF, OCR, конверсию Word и пометки reader.

`declared_range`, `returned_range` и `uncovered_ranges` используют полуоткрытые интервалы с нулевым началом. `next_start` передаётся в следующий вызов с тем же документом или участком. При `next_start=null` достигнут конец запрошенного диапазона. Покрытие нескольких вызовов определяется объединением их `returned_range` с учётом `column_scope`, если использовалась выборка столбцов.

## Шапка, продолжение и изображение

`header_refs` ссылается на строки с предполагаемыми названиями столбцов. `header_context` повторяет обнаруженную шапку и соседние строки за пределами основной выдачи. `source_titles` и `continuation_markers` дают адресуемые фрагменты для навигации. `adjacent_pages` перечисляет физически соседние страницы того же документа. Обход продолжения включает открытие соседнего листа и проверку его связи с текущей ведомостью по обозначению и содержанию.

Одна запись ведомости может занимать несколько извлечённых строк. Строка широкого листа может включать одновременно таблицу, фрагмент рисунка и примечание. При неоднозначной привязке значения используют координатный срез текста и `view_ref` для сверки с изображением. Геометрия изображения, объединённые ячейки и пропуски текстового слоя требуют такой сверки. Опись исходного reader помогает открыть участки вне каталога кандидатов. Пустая выдача OCR требует просмотра изображения.

## Синтетическая проверка

Из корня репозитория:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s experiments/package_review -p test_schedule_reader.py
```

[Исполняемые примеры](../experiments/package_review/test_schedule_reader.py) проверяют общий каталог, порядок и пагинацию, устойчивость адресов, чтение листа без потери пробелов и длинных строк, явную выдачу непокрытых интервалов, многострочную шапку, продолжение, раздельное происхождение текста и визуальные адреса. Восстановление после ошибки проверено повторным чтением правильного диапазона.
