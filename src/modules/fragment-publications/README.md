# Публикация фрагмента PDF

Инженер открывает принятый PDF из описи, нажимает «Подготовить фрагмент» и выбирает область получателей. В черновике он задаёт страницу и рамку в пунктах от верхнего левого угла видимой страницы. Для текстовой выдачи Reader сверяет дословную цитату с нативной строкой из слов внутри рамки. Для изображения Reader округляет границы внутрь рамки, сохраняет PNG при 144 dpi и возвращает действительные границы обрезки. У изображения предел 1 млн пикселей и 4 МиБ.

Из карточки инженер проверяет материал, выдаёт его в выбранную область с указанием основания и может отозвать выдачу. Версии 1, 2 и 3 обозначают черновик, выдачу и отзыв. Материал, версия оригинала, его SHA-256, профиль Reader и область закрепляются при создании. Для другой рамки, другого адресата или повторной выдачи после отзыва создаётся новая публикация.

Участник открывает карточку в разделе «Фрагменты» из списка доступных проектов. Для списка, карточки и PNG сервер проверяет текущую роль в указанной области и состояние публикации. Карточка участника содержит адрес и точную цитату или ссылку на текущую версию обрезки. Черновики и история доступны инженеру. Доступ к оригиналу, карте, OCR и пакетным наблюдениям проверяется их собственной проектной политикой. Пакетные привязки и публикации фрагментов хранятся независимо.

Базовый маршрут API — `/api/projects/:projectId/scopes/:scopeId/fragment-publications`. `POST` создаёт черновик. `POST /:publicationId/grant` и `POST /:publicationId/revoke` принимают `If-Match` и основание. Все три команды используют штатную защиту CSRF, квитанции идемпотентности и аудит доступа. PNG доступен по `GET /:publicationId/versions/:version/preview` в текущей версии. Материализация использует общий слот локального Reader.

- Сервер и реальные пакетные привязки: `FACADE_PACKAGE_INTEGRATION=1 node --test src/modules/harness/package-worker.integration.test.mjs` на отдельной синтетической БД, приватном S3 и отдельном журнале с локальным транспортом.
- Пользовательский сценарий в Chrome: `npm --prefix web run test:stand -- fragment-publications.spec.ts` на отдельной сборке и синтетической БД.
