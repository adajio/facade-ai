# Проверка конвертации DWG

На локальном сервере DWG открывает ODA File Converter 27.10 в изолированном процессе. Для установки и запуска используйте [инструкцию стенда](../../../../../infra/test-stand/README.md#брокер-конвертеров). Объём разрешённого использования описан в [записи по ODA](oda-terms.md).

Сопоставляйте результаты для одного SHA-256 оригинала. В протоколе сохраняйте идентификатор конвертера, SHA-256 производной, количество пространств, доступность графики и текстовых объектов, время и причину удержания. Успешную строку проверяйте повторным открытием той же версии. Чтобы оценить инженерный результат, проверьте адрес, область фасада, строку в матрице и формулировку в письме.
