# Сценарии для рабочего места · шаг 13

Входы — синтетические файлы из `fixtures/`. Эталон `gold/expected.json` читает только тест.
В управляемом маршруте вызовы ставятся через штатную очередь A/B. В проверке транспорта
подавать контролируемые ответы и считать оплаченные вызовы равными нулю.

1. DOCX. Показать находку с цитатой `2.40 mm`. Открыть из карточки. Проверить редакцию,
   раздел Wing M, таблицу 1, строку 2, колонку 3 и скачивание ровно исходных байтов.
   Для абзаца 3 проверить привязку примечания, если оно отображается в представлении.
2. XLSX. Открыть свидетельство столбца C строки 3 на листе Schedule M. Проверить
   формулу `B3*2`, сохранённый кэш `4.80`, исходную единицу из заголовка и причину
   отсутствия подтверждённого пересчёта. У C4 кэш отсутствует. Повторно открыть B3
   и проверить строку исходной точности `2.400000000000003` и формат `0.00 "mm"`.
   Пустой лист остаётся в описи и обязанностях.
3. DXF. Открыть Model, handle 32. Сопоставить его с handle 33, который имеет тот же
   итог `70 mm` и другую сборку. Убедиться, что обзор или увеличение возвращает PNG
   с заголовком и соседними строками. В Layout 1 доступен другой лист.
   Повторить на `partial.dxf` и проверить явные ограничения шрифта и внешней ссылки.
4. IFC и текст. Открыть `#42` и исходный GUID из карточки, затем вторую строку `notes.txt`.
   У обоих мест должна остаться ссылка на закреплённую версию оригинала.
5. PDF. Нативная выборка рамки из эталона даёт ноль кандидатов. Через сохранённый
   PNG увеличить и прочитать ZX-582, 8.65 mm. Проверить повёрнутый лист и отдельную
   причину нечитаемости страницы 3. Для OCR проверить хранение фактически поданных
   пикселей через `/api/v1/evidence/:id/ocr-input`.
6. Для RVT и произвольного расширения доступен оригинал и глубина «только оригинал».
   Для проблемных копий и выключенной конвертации доступны устойчивый исход
   и причина по единице. Независимые места остаются доступными.
7. Повторить открытие после перезапуска сервера. Сравнить SHA-256 выдачи, ID
   версии, адрес и цитату. Запретить прямое открытие чужому проекту. Отдельно
   различить карту представлений, доставленные A/B выдачи, ответы моделей,
   закреплённые наблюдения и элементы инженерной карточки.

Метаадрес карточки берётся из `observation.address.locator`. В `evidence.address.locator`
может храниться более широкая область открытия. Дополнительные поля строк хранятся
в `lines[].details` JSON, оригинал открывается через `originalHref`. В ответе метаданных
сохранённого OCR входное изображение адресуется полем `ocrInputHref`.
