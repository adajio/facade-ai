**Стабильная база 1.0** зафиксирована тегом `spec-v1.0`. Главный результат — обоснованное заключение инженера о комплектности присланного пакета для конкретного этапа и области работ. Сначала система точно распознаёт факты и их происхождение, сопоставляет все действующие материалы, показывает достаточность, пробелы, противоречия и неопределённость. Письмо нужно только при подтверждённой нехватке или противоречии.

В исходной версии [спецификация 1.0](docs/specification-v1.0.md) с приложениями об интерфейсе, сервере и мощности. [Единый документ для передачи команде](docs/Facade-AI-Specification-1.0.docx). Материалы редакций 0.x ниже сохраняют историю исследований.

Для версии 1.0 принят модульный монолит на TypeScript/Node.js, Svelte и PostgreSQL. В полном профиле Mastra две разные модели независимо исследуют один объём, при споре по отдельному вопросу ведущий разбирает обе позиции по оригиналам. Инженеру доступны исходные цитаты и адреса обоих читателей. Данные о стоимости накапливаются для последующей оптимизации. Объём распознавания и эталон качества задаются предметной задачей. Новый продукт имеет собственный каталог, хранилище и поставку.
